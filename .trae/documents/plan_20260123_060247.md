## 创建测试程序计划

### 目标

在 `d:\cvwork\inference_LiMR\test` 目录中创建一个完整的测试程序，使用现有的 pipeline 组件（Preprocessor、PostProcessor、TrtEngine）进行全 GPU 的预处理、推理和后处理。

### 文件结构

1. **test/test\_pipeline.cpp** - 主测试程序
2. **test/CMakeLists.txt** - CMake 构建配置（可选，或添加到主 CMakeLists.txt）

### 实现步骤

#### 1. 创建 test\_pipeline.cpp

包含以下功能：

* **初始化**: GLFW + ImGui + OpenGL 上下文

* **组件初始化**:

  * TrtEngine 加载模型（支持 .onnx 或 .engine 文件）

  * Preprocessor (256x256 输出尺寸)

  * PostProcessor

* **步骤 A - 输入**: 使用 cv::imread 读取测试图片，通过 Preprocessor 的 h\_pinned\_buffer 上传到 GPU

* **步骤 B - 预处理**: 调用 preprocessor->process() 进行 HWC→CHW 转换和归一化（全 GPU）

* **步骤 C - 推理**: 调用 engine->infer() 执行 TensorRT 推理（结果在 GPU 显存）

* **步骤 D - 后处理**: 调用 postprocessor->process() 生成热力图和掩码纹理

* **步骤 E - 渲染**: 在 ImGui 中显示原图、热力图、掩码叠加图

#### 2. 更新 CMakeLists.txt

添加新的可执行文件 target，链接必要的库：

* nvinfer\_10, cudart, nvonnxparser\_10

* OpenCV

* GLFW3, OpenGL32

* 所有必要的 CUDA kernels

#### 3. 关键实现细节

* 使用 `CudaInteropTexture` 类创建和渲染纹理

* 使用 `FrameTask` 结构存储中间数据

* 确保所有数据传输使用 GPU（H2D 仅在初始加载图片时）

* 支持动态阈值调整，实时更新掩码显示

### 预期结果

运行程序后，可以看到：

* 原图

* 热力图（伪彩色）

* 缺陷掩码（半透明红色）叠加在原图上

* 调整阈值滑块时，红色区域会相应变化

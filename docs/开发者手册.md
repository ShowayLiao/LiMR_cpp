# 开发者手册

## 1. 项目概述

### 1.1 核心功能

inference_LiMR是一个基于TensorRT的实时异常检测系统，专门用于视频流分析。系统支持单引擎和双引擎两种推理模式，能够高效地生成异常热力图，并提供直观的用户界面进行配置和监控。

### 1.2 技术栈

| 技术领域 | 核心技术 | 用途 |
|---------|---------|------|
| 编程语言 | C++ | 主要开发语言 |
| GPU计算 | CUDA | 并行计算和内存管理 |
| 深度学习推理 | TensorRT | 模型加载和高效推理 |
| 图像处理 | OpenCV | 图像预处理、后处理和可视化 |
| 图形渲染 | OpenGL | 实时视频和热力图渲染 |
| 用户界面 | ImGui | 交互式控制面板 |

### 1.3 目标用户

- 工业质量检测工程师
- 实时监控系统开发人员
- 深度学习推理加速研究人员
- 系统集成工程师

### 1.4 应用场景

- 工业产品表面缺陷检测
- 实时视频监控异常分析
- 生产流水线质量控制
- 智能设备故障检测

## 3. 流水线架构详解

### 3.1 整体架构

inference_LiMR采用多线程流水线架构，实现了从视频捕获到推理再到可视化的完整流程。系统主要由以下几个核心模块组成：

1. **输入线程（InputThread）**：负责从视频源读取帧数据并进行初步处理
2. **推理线程（InferenceThread）**：执行模型推理和相关处理
3. **预处理（Preprocessor）**：对帧数据进行缩放、颜色空间转换和归一化处理
4. **后处理（PostProcessor）**：生成异常热力图并与原始图像叠加
5. **CUDA渲染模块**：实现GPU加速的图像渲染
6. **用户界面**：提供交互式控制和结果展示

### 3.2 数据流向

```
graph TD
    A[输入源<br>视频文件/摄像头/RTSP] -->|多线程IO读取| B[CPU 帧缓存]
    B -->|异步DMA拷贝| C[CUDA 预处理层<br>（缩放/归一化/色域转换）]
    G[ImGui 控制面板<br>（参数配置/控制指令）] -->|配置参数| C
    G -->|控制指令| D[TensorRT 推理引擎<br>（FP32/FP16 推理）]
    C -->|GPU显存内流转| D
    D -->|输出异常张量[1,1,H,W]| E[CUDA 后处理层<br>（热图生成/阈值分割/颜色编码）]
    E -->|CUDA-OpenGL 互操作| F[OpenGL 渲染层<br>（零拷贝纹理映射）]
    G -->|显示模式切换| F
    F -->|多模式可视化| H[输出展示<br>（原始视频/热图/叠加）]
    E -->|异常结果数据| I[结果输出<br>（异常分数/缺陷坐标）]
```

### 3.3 关键流程

1. **视频帧捕获**：通过OpenCV从视频文件或摄像头读取帧数据
2. **预处理**：对帧数据进行缩放、颜色空间转换和归一化处理
3. **模型推理**：使用TensorRT执行深度学习模型推理
4. **后处理**：生成异常热力图并与原始图像叠加
5. **渲染显示**：使用OpenGL和CUDA互操作技术实现高效渲染
6. **用户交互**：通过ImGui提供实时参数调整和结果展示

## 4. 技术亮点

### 4.1 GPU加速

- **CUDA核心优化**：使用CUDA kernels实现高效的图像处理和计算
- **GPU内存管理**：采用DeviceBuffer管理GPU内存，减少内存泄漏风险
- **CUDA-OpenGL互操作**：实现零拷贝的GPU-GPU数据传输，提高渲染性能
- **NPP库加速**：使用NVIDIA Performance Primitives库进行优化的图像处理

### 4.2 实时性能

- **多线程设计**：视频捕获和处理分离，提高系统响应速度
- **TensorRT推理**：利用TensorRT的优化能力，实现高效的模型推理
- **内存复用**：预分配和复用GPU内存缓冲区，减少内存分配开销
- **流水线并行**：使用CUDA流实现计算和内存拷贝的并行执行

### 4.3 灵活配置

- **双引擎模式**：目前暂不支持学生-教师模型的双引擎推理模式
- **动态分辨率**：支持实时调整渲染分辨率
- **多精度支持**：支持FP32和FP16精度的模型推理
- **可配置参数**：通过UI界面实时调整各种系统参数

### 4.4 可视化技术

- **三视图布局**：原始图像、热力图和叠加结果的三视图实时展示
- **半透明叠加**：使用CUDA实现高效的半透明热力图叠加
- **动态色彩映射**：支持多种色彩映射方案，增强异常区域的可视化效果
- **实时阈值调整**：通过滑块实时调整异常检测的阈值

**关键实现**：

**代码位置**：
- `include/app_config.h`：定义应用配置结构体和接口
- `src/app_config.cpp`：实现配置管理功能

**功能定位**：实现GPU加速的图像渲染，支持视频帧和热力图的高效显示。

**关键实现**：
- 使用CUDA-OpenGL互操作纹理，实现零拷贝的GPU-GPU数据传输
- 支持两种渲染模式：热力图和视频帧
- 内部管理CUDA和OpenGL资源，确保正确释放
- 提供纹理ID访问接口，便于外部渲染

**代码位置**：
- `include/cuda_render.h`：定义CUDA渲染接口
- `src/cuda_render.cu`：实现CUDA渲染功能

**关键实现**：

**功能定位**：执行模型推理和相关处理，协调预处理和后处理模块。

## 6. UI开发与使用

### 6.1 界面布局

系统界面采用三栏布局设计：

1. **左侧边栏**：参数配置区域，包括视频源、模型路径、推理模式等设置
2. **右侧主视图**：结果显示区域，包含三个子视图：
   - 原始视频帧
   - 异常热力图
   - 叠加结果图
3. **底部控制栏**：包含启动/停止、暂停/恢复等控制按钮

### 6.2 核心功能

- **视频源配置**：支持视频文件、摄像头输入和单图输入
- **模型配置**：支持单引擎和双引擎两种模式
- **精度选择**：支持F32和F16两种精度
- **阈值调整**：实时调整异常检测的阈值
- **分辨率设置**：支持多种预设分辨率，适应不同显示需求
- **实时监控**：实时显示处理结果和系统状态

### 6.3 使用流程

1. **配置参数**：在左侧边栏输入视频源路径、模型路径等参数
2. **启动系统**：点击"Apply & Reload"按钮启动系统
3. **调整参数**：根据需要调整阈值、分辨率等参数
4. **监控结果**：在右侧主视图观察处理结果
5. **控制运行**：使用底部控制栏的按钮控制系统运行状态

### 6.4 常见操作

- **暂停/恢复**：点击"Pause"按钮暂停处理，点击"Resume"按钮恢复处理
- **重置系统**：点击"Reset"按钮重置系统到初始状态
- **调整分辨率**：在左侧边栏选择合适的分辨率预设
- **调整阈值**：使用阈值滑块调整异常检测的灵敏度

## 10. 故障排除与调试

### 10.1 常见问题

1. **无法打开视频源**：
   - 检查视频文件路径是否正确
   - 检查摄像头是否可用
   - 确保视频格式受支持

2. **模型加载失败**：
   - 检查引擎文件路径是否正确
   - 确保引擎文件与当前CUDA版本兼容
   - 检查引擎文件是否完整

3. **性能问题**：
   - 尝试降低输入分辨率
   - 使用F16精度
   - 检查GPU利用率，确保没有其他进程占用大量GPU资源

4. **异常图全蓝或全红**：
   - 检查模型输出是否正确
   - 调整缺陷阈值
   - 检查预处理和后处理参数

5. **CUDA错误**：
   - 检查CUDA版本是否与TensorRT兼容
   - 确保GPU驱动程序已更新

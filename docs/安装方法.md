# 开发环境配置

AnomaRT 使用 OpenCV 完成图片读取、视频解码、摄像头输入和 `cv::Mat` 数据管理；GPU
预处理与后处理由 CUDA/NPP 和自定义 CUDA kernel 完成。因此，**不需要编译或安装
CUDA 版 OpenCV**。

## 开发依赖

- Windows 10/11 x64；
- Visual Studio 2022 Build Tools，并勾选“使用 C++ 的桌面开发”；
- CMake 3.21 或更高版本，以及 Ninja；
- CUDA Toolkit 11.8；
- TensorRT 10.12 Windows SDK；
- OpenCV 4.5.5 Windows 预编译包。

运行或测试 GPU 推理时，机器还需要安装兼容的 NVIDIA 驱动。

## 安装 OpenCV

下载并解压标准的 Windows OpenCV 4.5.5 预编译包即可。无需从源码编译，无需
`opencv_contrib`，也无需启用 OpenCV CUDA 模块。

以下示例将其解压至 `C:\deps\OpenCV`：

```text
C:\deps\OpenCV\build\x64\vc16\lib  # OpenCVConfig.cmake 与导入库
C:\deps\OpenCV\build\x64\vc16\bin  # 运行时 DLL
```

## 配置项目

在当前 PowerShell 会话中设置依赖路径：

```powershell
$env:LIMR_TRT_ROOT = 'C:\deps\TensorRT'
$env:LIMR_OPENCV_DIR = 'C:\deps\OpenCV\build\x64\vc16\lib'
$env:LIMR_OPENCV_BIN_DIR = 'C:\deps\OpenCV\build\x64\vc16\bin'
```

然后配置、构建并生成可分发目录：

```powershell
cmake --preset windows-release
cmake --build --preset windows-release --parallel
cmake --install out\build\windows-release
```

生成结果位于 `out\dist\AnomaRT`，其中包含 `AnomaRT.exe` 以及自动收集的
OpenCV、CUDA 和 TensorRT 运行时 DLL。

## 容器构建

如需可复现的 Windows 编译环境，请参阅
[`docker/windows/README.md`](../docker/windows/README.md)。工具链镜像中只需放置
同一份普通 OpenCV 预编译包到 `C:\deps\OpenCV`，不需要 CUDA 版 OpenCV。
